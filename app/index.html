One-time setup

Add your Firebase keys

Open firebase-config.js in this folder and paste your project's config, then reload. It takes about five minutes:

  1. Create a free project at console.firebase.google.com
  2. Add a Web app and copy its firebaseConfig
  3. Enable Authentication → Email/Password
  4. Create a Firestore Database, then paste the contents of firestore.rules into its Rules tab
  5. Paste the config into firebase-config.js and reload

Full walkthrough is in README.md.
